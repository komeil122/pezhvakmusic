# Pezhvak Soundscape

Create a new project named Pezhvak Music. Build a polished, responsive music player dashboard inspired by the attached reference image, using the same near-black charcoal surfaces, subtle borders, muted gray typography, and restrained accent tone as the Aura AI/Pezhvak project in this workspace. Include a left navigation/sidebar with Pezhvak Music identity, Home, Library, Playlists, Favorites, Recently Played and playlist links; a main discovery area with search, welcome area, recently played album cards, playlists, and artists; a right Now Playing panel; and a bottom playback bar. Use original placeholder/generated artwork and fictional demo content, not copyrighted artist images or album art. Add believable interactive UI controls: search filtering, selecting an album/playlist updates Now Playing, play/pause and next/previous state, favorite toggle, volume and progress slider. Make it usable at desktop and gracefully responsive. Do not publish.

This project was built with [pezhvak](https://pezhvak.dev).
